# Investment Hub

Administração, controlo e contabilização de carteiras de investimento de seguradoras de reduzida ou média complexidade: obrigações, ações cotadas e participações não cotadas, com afetação de ativos, IFRS 9, Solvência II e integração com a contabilidade.

- **Mockup:** abrir `3 - Mockups/mockup-final.html` no browser (ou `index.html` no GitHub Pages).
- **Especificação:** `2 - Ficheiros MD/especificacao-gestao-investimentos.md`
- **Análise de mercado:** `2 - Ficheiros MD/analise-mercado.md`
- **Plano e decisões:** `2 - Ficheiros MD/plano-gestao-investimentos.md`

Gerar o mockup e correr os testes do motor de cálculo:

```bash
cd "1 - Código VSC"
node gerar-mockup.js
node testes/motor.test.js
```

Os dados de demonstração são fictícios (Seguradora A).
